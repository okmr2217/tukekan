# 2. 機能要件

## 2.1 MVP機能（初期リリース）

### 認証機能

- [ ] ログイン/ログアウト
- [ ] 新規登録
- [x] オンボーディング（登録直後に 表示名 → 取引ボタン表示 → 最初の相手 → 最初の取引 を順に案内。相手・取引は飛ばせる）

### ホーム画面（タブ切替）

- [ ] **残高タブ**: 総貸借残高 + 相手ごとの残高一覧
- [ ] **履歴タブ**: 自分の全取引を時系列で一覧表示
- [ ] 相手をタップで取引履歴画面へ遷移

### 取引登録（モーダル）

- [ ] 相手の選択（登録済みPartner or 新規作成）
- [ ] 金額入力（プラス=貸し、マイナス=借り/返済）
- [ ] 説明（任意、過去履歴からサジェスト）
- [ ] 日付（デフォルト: 今日）

### 取引履歴画面

- [ ] 特定の相手との取引履歴一覧
- [ ] 現在の残高表示

### 設定画面

- [ ] プロフィール編集（表示名）
- [ ] ログアウト

### ナビゲーション

- [ ] ボトムバー（相手、すべての取引、統計、メニュー）
- [ ] FAB（取引登録）
- [ ] ヘッダー（設定アイコン）

## 2.2 将来機能

| 機能             | Phase | 説明                                                |
| ---------------- | ----- | --------------------------------------------------- |
| 全額精算         | 2     | 残高を0にする相殺取引を自動登録                     |
| 取引タイプ       | 2     | LEND/BORROW/REPAYMENT等を明示（借りと返済を分ける）。利息は `Transaction.kind = "INTEREST"` として実装済み |
| 返済の充当先を選ぶ | 2   | 現在マイナス取引は「まず未払利息、余りを元本」に自動充当される。取引ごとに「利息に充当／元本に充当」を選べるようにする案（実装コストとUIの複雑さから見送り中） |
| 複数人での割り勘 | 2     | 1回の支出を複数人に分割して登録                     |
| CSVエクスポート  | 2     | データバックアップ機能                              |
| 通知機能         | 3     | 返済期日のリマインダー（PWA Push）                  |
| グラフ表示       | 3     | 月ごとの貸借推移を可視化                            |
