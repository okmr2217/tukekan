## 4.2 ナビゲーション設計

### ボトムバーナビゲーション採用

| 方式                   | メリット                    | デメリット                       |
| ---------------------- | --------------------------- | -------------------------------- |
| ハンバーガーメニュー   | 画面広く使える              | タップ数が増える、発見されにくい |
| **ボトムバー（採用）** | 主要機能に1タップでアクセス | 画面下部を占有、項目数に制限     |

**採用理由:**

- 画面数が少ない（4項目）→ ボトムバーに収まる
- 頻繁に使う機能へのアクセスを最優先
- スマホの片手操作で親指が届きやすい

### ボトムバーの項目（確定）

| アイコン | ラベル       | パス            | 説明                         |
| -------- | ------------ | --------------- | ---------------------------- |
| 👥       | 相手         | `/`             | 相手ごとの残高（メイン機能） |
| 📋       | すべての取引 | `/transactions` | 全取引の一覧                 |
| 📊       | 統計         | `/statistics`   | 貸借の集計                   |
| ☰        | メニュー     | `/menu`         | 相手管理・設定・ヘルプ       |

**設定ページをボトムバーに入れない理由:**

- 使用頻度が低い
- ヘッダーの⚙️アイコンからアクセス可能

**取引登録はFAB（右下の+ボタン）で対応:**

- 最も頻繁に使う操作なので常に目立つ位置に配置
- モーダルで開くのでページ遷移不要

## 4.11 取引カード・取引詳細ダイアログ

取引の見た目は**認証ページ（アプリ本体）と公開ページ（`/share/[token]`）で同じコンポーネント**を使う。
違うのは「見ている人」だけなので、`viewpoint`（`"owner"` / `"partner"`）で符号と文言を切り替える。

- 実装: `src/components/features/transaction/transaction-card.tsx` / `transaction-detail-modal.tsx`
- 文言・符号の変換: `src/lib/transaction-wording.ts`
- 配色: `src/components/features/transaction/transaction-tone.ts`

### 取引カード

「取引の情報」を左、「残高の情報」を右の固定幅カラムに分ける。
一覧では残高が縦にそろうので、残高の推移を列として追える。

```
┌────────────────────────────────┬──────────┐
│ [貸した] [口座] 相手名    18:30 │ 貸している│ ← 左: 名目・文脈・取引日時
│ 飲み会の立て替え 📝     ¥3,000 │  ¥12,000 │ ← 右: この取引を反映した後の残高
└────────────────────────────────┴──────────┘
```

- **金額は色を付けず黒（foreground）で出し、マイナスのときだけ符号を付ける**。
  色は残高（債権 = 緑 / 債務 = 赤）に取っておき、取引の向きは名目チップが示す
- 幅が足りないときに削るのは口座名・相手名だけ。名目チップと日時は常に残す
- 日時は取引日時のみ（`formatTransactionTime`）。60分以内は「N分前」、今日は時刻、昨日は「昨日 HH:mm」、
  **それ以前は日付だけ**（時刻は詳細ダイアログで出す）。作成・更新はカードには出さない
- メモは本文を出さずアイコンだけにして、本文はダイアログで読ませる
- 口座名チップ・相手名は、それらが混ざって並ぶ一覧でだけ出す

### 取引の名目（タイプ）

名目は金額の向きだけでは決まらない。**その取引を反映する前の残高**と組み合わせて4通りになる。

| 反映前の残高 | 金額 +（債権が増える） | 金額 −（債務が増える） |
| --- | --- | --- |
| 0以上（貸している） | 貸した | 返済された |
| マイナス（借りている） | 返済した | 借りた |

- 利息（`kind = "INTEREST"`）は元本の貸し借りと別勘定なので、名目を「利息」（琥珀色）に置き換える
- 公開ページでは符号を反転してから判定するので、オーナーの「貸した」は相手側で「借りた」になる

### 残高の表現

残高は絶対値＋ことばで、債権か債務かがすぐ分かるようにする（符号に頼らない）。

| 見ている人の残高 | ことば | 立場 | 色 |
| --- | --- | --- | --- |
| プラス | 貸している残高 | 債権 | emerald |
| マイナス | 借りている残高 | 債務 | red |
| ゼロ | 残高（貸し借りなし） | 精算済み | muted |

### 取引詳細ダイアログ

```
┌──────────────────────────────────────┐
│ 取引の詳細                        [×] │
├──────────────────────────────────────┤
│              [貸した]                 │
│              ¥3,000                   │
│          たなかさんに貸しました        │
│                                       │
│ 取引                                  │
│ ┌───────────────────────────────────┐ │
│ │ 用途      飲み会の立て替え         │ │
│ │ メモ      駅前の居酒屋             │ │
│ │ 取引日時  2026年9月21日(月) 18:30  │ │
│ │ 口座      生活費                   │ │
│ └───────────────────────────────────┘ │
│ 残高                                  │
│ ┌───────────────────────────────────┐ │
│ │ 取引前        →         取引後     │ │
│ │ 貸し借りなし          貸している   │ │
│ │ ¥0                      ¥3,000     │ │
│ │ たなかさんから受け取る残高（債権） │ │
│ └───────────────────────────────────┘ │
│ 作成 … ・ 更新 …                      │ ← 認証ページのみ
├──────────────────────────────────────┤
│ [編集] [アーカイブ] [🗑]               │ ← 認証ページのみ（フッター）
└──────────────────────────────────────┘
```

- 金額はカードと同じく黒。マイナスのときだけ符号を付ける
- フッター（編集・アーカイブ・削除）は `actions` を渡したときだけ描画する。公開ページでは渡さないので出ない
- 作成・更新日時は記録者だけの情報。公開ページのデータには `createdAt` を含めないので自然に出ない
