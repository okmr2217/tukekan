## 4.2 ナビゲーション設計

### ボトムバーナビゲーション採用

| 方式                   | メリット                    | デメリット                       |
| ---------------------- | --------------------------- | -------------------------------- |
| ハンバーガーメニュー   | 画面広く使える              | タップ数が増える、発見されにくい |
| **ボトムバー（採用）** | 主要機能に1タップでアクセス | 画面下部を占有、項目数に制限     |

**採用理由:**

- 画面数が少ない（4項目）→ ボトムバーに収まる
- 頻繁に使う機能へのアクセスを最優先
- スマホの片手操作で親指が届きやすい

### ボトムバーの項目（確定）

| アイコン | ラベル       | パス            | 説明                         |
| -------- | ------------ | --------------- | ---------------------------- |
| 🏠       | ホーム       | `/`             | 全体の残高・相手ごとの残高・最近の取引（メイン機能） |
| 📋       | すべての取引 | `/transactions` | 全取引の一覧                 |
| 📊       | 統計         | `/statistics`   | 貸し借りの流れ・返済の傾向   |
| ☰        | メニュー     | `/menu`         | 設定・使い方ガイド           |

**設定ページをボトムバーに入れない理由:**

- 使用頻度が低い
- ヘッダーの⚙️アイコンからアクセス可能

**取引登録はFAB（右下の+ボタン）で対応:**

- 最も頻繁に使う操作なので常に目立つ位置に配置
- モーダルで開くのでページ遷移不要
- 表示するのはホーム・すべての取引・相手ページ（`src/components/layouts/fab-controller.tsx`）。
  相手ページではその相手（口座で絞り込み中ならその口座も）を初期選択する。ほかの画面では相手は未選択で開く

## 4.5 ホーム画面 レイアウト

相手一覧を主役に、上に全体の残高、下に最近の取引を置く。取引の作成は FAB から。

```
┌────────────────────────────────┐
│  ホーム                        │
├────────────────────────────────┤
│ ┌────────────────────────────┐ │
│ │ 差し引きで受け取ります     │ │ ← 全体の残高（緑=受け取る / 赤=返す）
│ │ ¥25,937                    │ │
│ ├──────────────┬─────────────┤ │
│ │ ●貸している  │ ●借りている │ │ ← 相手ごとのいまの残高を向きで分けて合計
│ │ ¥60,903      │ ¥34,966     │ │
│ └──────────────┴─────────────┘ │
│  相手ごとの残高   [相手を追加] │
│ ┌────────────────────────────┐ │
│ │ えいご [2口座]   貸している > │ │
│ │ 3日前 · ランチ代   ¥35,773   │ │  ← 債権は緑・債務は赤・精算済みはグレー
│ └────────────────────────────┘ │
│ ┌────────────────────────────┐ │
│ │ ほんじょう       借りている > │ │
│ │ 2週間前 · 立替え   ¥34,966   │ │  ← 金額は絶対値。向きは色とラベルで示す
│ └────────────────────────────┘ │
│  最近の取引        すべて見る >│
│ ┌────────────────────────────┐ │
│ │ [貸した] えいご     18:30  │ │  ← 取引カード（4.11）を5件
│ │ 麻雀                        │ │
│ └────────────────────────────┘ │
│                         [＋]   │
├────────────────────────────────┤
│  [🏠]  [📋]  [📊]  [☰]        │
│ ホーム 取引  統計  メニュー    │
└────────────────────────────────┘
```

- 実装: `src/app/(main)/page.tsx`・`src/components/features/home/`（`balance-summary-card.tsx`・`recent-transactions-section.tsx`）・`src/components/features/partner/partner-list-section.tsx`
- **全体の残高**は、差し引き（受け取る／返す）を大きく出し、その下に「貸している」「借りている」の合計を並べる。
  「貸している」「借りている」は相手ごとの**いまの残高**を向きで分けて足したもので、統計の累計（これまでに貸した額）とは別物
- 全体の残高はアーカイブしていない相手だけで計算する（統計と同じ）
- 相手がいないときは全体の残高を出さず、相手の追加を促す
- **最近の取引**は新しい順に5件。取引後の残高は口座の全履歴から積み上げるので、全件を取ってから先頭5件だけ出す。
  6件以上あるときだけ「すべて見る」を出す。取引がないときはセクションごと出さない
- 最後のカードが FAB に隠れないよう、下端に余白をとる

## 4.11 取引カード・取引詳細ダイアログ

取引の見た目は**認証ページ（アプリ本体）と公開ページ（`/share/[token]`）で同じコンポーネント**を使う。
違うのは「見ている人」だけなので、`viewpoint`（`"owner"` / `"partner"`）で符号と文言を切り替える。

- 実装: `src/components/features/transaction/transaction-card.tsx` / `transaction-detail-modal.tsx`
- 文言・符号の変換: `src/lib/transaction-wording.ts`
- 配色: `src/components/features/transaction/transaction-tone.ts`

### 取引カード

上段に金額以外の取引の情報、下段の左に取引の金額、右に残高を置く。
下段の左右は「ラベル＋右寄せの数字」という同じ組み方なので、位置もサイズもそろう。

```
┌──────────────────────────────────────┐
│ [貸した] [口座] 相手名        18:30  │ ← 上段: 名目・文脈・取引日時
│ 飲み会の立て替え                     │ ← 上段: 用途（カード幅を使える）
│ 駅前の居酒屋                         │ ← 上段: メモ（あるときだけ・2行まで）
├──────────────────┬───────────────────┤
│ 金額      ¥3,000 │ 残高      ¥12,000 │ ← 下段: 左=取引の金額
└──────────────────┴───────────────────┘    右=反映後の残高（色で債権/債務）
```

- **金額は色を付けず黒（foreground）で出し、マイナスのときだけ符号を付ける**。
  色は残高（債権 = 緑 / 債務 = 赤）に取っておき、取引の向きは名目チップが示す
- 残高のラベルは「残高」だけにして、債権か債務かは色で示す。
  ことばでの説明（貸している／借りている・債権／債務）は詳細ダイアログで出す
- 用途が上段で横幅をまるごと使えるので、金額が大きくても用途が省略されにくい。
  一覧では金額も残高もそれぞれ縦にそろうので、推移を列として追える
- 幅が足りないときに削るのは口座名・相手名だけ。名目チップと日時は常に残す
- 日時は取引日時のみ（`formatTransactionTime`）。60分以内は「N分前」、今日は時刻、昨日は「昨日 HH:mm」、
  **それ以前は日付だけ**（時刻は詳細ダイアログで出す）。作成・更新はカードには出さない
- メモがあれば用途の下に本文を出す。カードでは2行までにして、全文はダイアログで読ませる
- 口座名チップ・相手名は、それらが混ざって並ぶ一覧でだけ出す

### 取引の名目（タイプ）

名目は金額の向きだけでは決まらない。**その取引を反映する前の残高**と組み合わせて4通りになる。

| 反映前の残高 | 金額 +（債権が増える） | 金額 −（債務が増える） |
| --- | --- | --- |
| 0以上（貸している） | 貸した | 返済された |
| マイナス（借りている） | 返済した | 借りた |

- 利息（`kind = "INTEREST"`）は元本の貸し借りと別勘定なので、名目を「利息」（琥珀色）に置き換える
- 公開ページでは符号を反転してから判定するので、オーナーの「貸した」は相手側で「借りた」になる

### 残高の表現

残高は絶対値＋ことばで、債権か債務かがすぐ分かるようにする（符号に頼らない）。

カードでは色だけ、詳細ダイアログではことばでも示す。

| 見ている人の残高 | ことば（ダイアログ） | 立場 | 色 |
| --- | --- | --- | --- |
| プラス | 貸している | 債権 | emerald |
| マイナス | 借りている | 債務 | red |
| ゼロ | 貸し借りなし | 精算済み | muted |

### 取引詳細ダイアログ

```
┌──────────────────────────────────────┐
│ 取引の詳細                        [×] │

│              [貸した]                 │
```

## 4.12 統計ページ

統計は「全体の統計（`/statistics`）」と「相手ごとの統計（`/partners/[id]/statistics`）」の2つ。
以前あった `/statistics`（相手タブ／全体タブ）と `/statistics/accounts`（口座別）はこの2つにまとめた（`/statistics/accounts` はリダイレクトだけ残す）。

### 役割の分け方

- **今の残高はホームと相手ページの役目。** 統計は「どう動いてきたか」（名目ごとの流れ・推移・返済の傾向）を主役にし、ホームと同じ一覧を並べない
- ボトムバーに置くのは、相手と期間をまたいで見渡せる唯一のページだから。メニューは設定・使い方ガイドだけにする

### 名目の扱い

- 「貸出／借入」のような符号の合計ではなく、取引カードと同じ名目（貸した／返済された／借りた／返済した／利息）で集計する
- 名目は「取引を反映する前の残高」で決める。残高が0をまたぐ取引は分割する（例: 残高 +3,000 に -5,000 → 返済された 3,000 ＋ 借りた 2,000）
- 名目の判定と返済の充当は口座ごとに計算してから合算する
- 表示は「貸し」（貸した・返済された・利息）と「借り」（借りた・返済した・利息）の2枚。一度も動きのない側は出さない
- 色は取引カードの名目チップと同じ（貸した・返済した = 緑、借りた・返済された = 赤、利息 = 琥珀）。グラフは上に「渡したお金」、下に「受け取ったお金」を積む

### 返済の傾向（信用度の目安）

- 貸し（借り）は古いものから順に返済で埋まるとみなす（先入れ先出し）
- 出す数字: 返ってくるまでの平均日数（金額で重み付け）／1ヶ月以内に返った割合／返してもらった金額／まだ返っていない金額といちばん古い分の経過日数／精算した回数（相手ごとのみ）
- 1ヶ月たっていない未返済分は「1ヶ月以内に返った割合」の判定に入れない
- 点数やランクにはせず、判断の材料になる数字だけを見せる
- 相手の返済（自分の貸し）と、自分の返済（自分の借り）を別々に出す

### 全体の統計

```
┌────────────────────────────────┐
│  統計                          │
├────────────────────────────────┤
│ [直近12ヶ月][今年][全期間]     │  ← ?period=
│ 貸し借りの流れ                 │
│ ┌──────────┐┌──────────┐      │
│ │貸し       ││借り       │      │
│ │貸した  ¥ ││借りた  ¥ │      │
│ │返済された¥││返済した ¥ │      │
│ └──────────┘└──────────┘      │
│ 月ごとの推移（積み上げ棒）     │  ← 表は折りたたみ
│ 残高の推移（月末の貸している／借りている） │
│ 返済の傾向（相手から／あなた） │
│ 動きのない貸し借り（60日以上） │
│ 相手ごと → 相手ごとの統計へ    │
│ 利息（利子のある口座があるとき）│
└────────────────────────────────┘
```

### 相手ごとの統計

- 入口は相手ページのヘッダー右の統計アイコンと、全体の統計の「相手ごと」
- 上から: 概要（残高・付き合いの長さ・取引回数）→ 残高の推移 → 返済の傾向 → 貸し借りの流れ → 月ごとの推移（直近12ヶ月）→ よく使う用途 → 口座ごと
- **口座が複数ある相手**: 初期表示は全口座の合算。上部のチップで1つの口座に絞り込める（相手ページと同じ `?ledger=`）。「口座ごと」の内訳は全口座表示のときだけ出す

### 集計の対象

- アーカイブ済みの取引は含めない
- アーカイブ済みの相手は含める（相手のアーカイブはホームの一覧と取引フォームの候補から外すだけ）
