# ツケカンをはじめる

ツケカンは、友だちや家族とのお金の貸し借りを**自分ひとりで記録しておく**ためのアプリです。「誰に、いくら貸していて、いくら借りているか」をいつでも確かめられます。

## ツケカンの考え方

- **記録するのはあなただけです。** 相手がツケカンを使っている必要はありません。相手の名前を登録すれば、その日から記録を始められます
- **相手に通知はいきません。** 記録したことが相手に伝わることはありません。相手にも同じ記録を見てほしいときは、[共有リンク](/help/share)を送ります
- **相手もツケカンを使っていても、記録は連動しません。** お互いがそれぞれ自分の記録をつける形です

## 3つのステップ

### 1. 相手を登録する

ホームの「相手を追加」から、貸し借りをする相手の名前を登録します。くわしくは[相手と口座](/help/partners)を見てください。

### 2. 取引を記録する

画面右下の「＋」ボタンから、「貸した」「借りた」などを金額といっしょに記録します。くわしくは[取引と残高](/help/transactions)を見てください。

### 3. 残高を見る

ホームに、全体の残高と相手ごとの残高が出ます。**緑は受け取る側、赤は返す側**です。色の見かたは[取引と残高](/help/transactions)の「残高と色の見かた」にまとめてあります。

## 登録と最初の設定

新規登録に使うのはメールアドレスとパスワード（8文字以上）だけです。登録が終わると、4つのステップで最初の設定を案内します。

| ステップ | 内容 |
| --- | --- |
| 1. 表示名 | 共有リンクを送った相手に表示される名前です（50文字まで） |
| 2. ボタン表示 | 取引を記録するときのボタンの言い方を選びます（「貸し借り両方」「よく貸す」「よく借りる」） |
| 3. 相手 | 最初の相手を登録します |
| 4. 取引 | その相手との直近の貸し借りを1件記録します |

相手と取引のステップは「あとで登録する」「あとで記録する」で飛ばせます。どのステップの内容も、あとから変えられます。

## 画面の見取り図

画面の下に4つのタブが並んでいます。

| タブ | 何をするところか |
| --- | --- |
| ホーム | 全体の残高、相手ごとの残高、最近の取引。日々の確認はほぼここで済みます |
| すべての取引 | すべての相手との取引を並べて、検索・絞り込みができます |
| 統計 | 貸し借りの流れや、返済にかかっている日数を見られます |
| メニュー | 設定と、この使い方ガイドへの入口です |

ホーム・すべての取引・相手のページでは、右下に取引を記録する「＋」ボタンが出ます。

## ホーム画面に追加する

ツケカンはスマートフォンのホーム画面に追加して、アプリのように使えます。

- **iPhone（Safari）**：画面下の共有ボタンから「ホーム画面に追加」
- **Android（Chrome）**：右上のメニューから「ホーム画面に追加」または「アプリをインストール」

## 設定でできること

メニューの「設定」で、次のことができます。

| 項目 | 内容 |
| --- | --- |
| 表示名 | 共有リンクの公開ページに出る名前を変えます（50文字まで） |
| メールアドレス | ログインに使うメールアドレスを確かめられます（変更はできません） |
| パスワード | 今のパスワードと新しいパスワード（8文字以上）を入れて変えます |
| 取引ボタンの表示 | 取引を記録するときのボタンの言い方を切り替えます（[取引と残高](/help/transactions)の「取引ボタンの表示」） |
| テーマ | 「システム」「ライト」「ダーク」から選びます。「システム」はスマートフォンの設定に合わせます |
| ログアウト | この端末からログアウトします |
