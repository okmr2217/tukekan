# 相手と口座

貸し借りをする人を「相手」と呼びます。取引はかならずどれかの相手との取引として記録されます。相手ごとの貸し借りをさらに分けて管理したいときに使うのが「口座」です。

## 相手を追加する

ホームの「相手ごとの残高」の「相手を追加」から、相手の名前を入れて登録します。

- 相手がツケカンを使っていなくても登録できます。相手の了承やアカウントは要りません
- 名前は50文字までです。**同じ名前の相手は2人登録できません。** 同じ名前の友だちがいるときは「たろう（大学）」のように区別してください
- 相手を登録すると、「通常」という名前の口座が1つ自動で作られます

## 相手のページ

ホームで相手をタップすると、その相手のページが開きます。

| 場所 | 内容 |
| --- | --- |
| 残高 | その相手との残高の合計。「◯◯さんから受け取ります」「◯◯さんに返します」「◯◯さんとは精算済みです」のどれかが添えられます |
| 口座 | 口座ごとのカード。口座が2つ以上あると、口座ごとの残高も出ます |
| 共有リンク | 相手に残高を見せるためのリンク（[共有リンク](/help/share)） |
| 取引一覧 | その相手とのすべての口座の取引 |

右上の2つのアイコンから、その相手の統計（[統計の見かた](/help/statistics)）と、相手の設定を開けます。このページで「＋」ボタンを押すと、この相手が選ばれた状態で取引を記録できます。

## 名前の変更・アーカイブ・削除

相手のページの右上の設定アイコンから、「相手の管理」を開きます。

### 名前を変更する

「名前を変更」から変えられます。相手のページと共有リンクは、名前を変えてもそのまま使えます。

### アーカイブする

やり取りが一段落した相手は、アーカイブしておくと一覧がすっきりします。アーカイブで変わること・変わらないことは次のとおりです。

| 変わること | 変わらないこと |
| --- | --- |
| ホームの相手一覧に出なくなる | 貸し借りの記録と残高はそのまま残る |
| 取引を記録するときの相手の候補に出なくなる | ホームの合計、すべての取引、統計には含まれる |
| **利子を設定した口座でも、利息が付かなくなる** | 共有リンクはそのまま使える |

アーカイブした相手は、ホームの相手一覧の下にある「アーカイブ済みの相手」から見られます。元に戻すときは、その相手のページの上に出る「解除する」か、相手の管理の「アーカイブを解除」を押します。

### 削除する

「この相手を削除」で相手を削除すると、**その相手との取引もすべて消え、元に戻せません。** 記録を残しておきたいなら、削除ではなくアーカイブを選んでください。

## 口座

口座は、1人の相手との貸し借りを分けて管理するためのまとまりです。**多くの場合、口座は最初の「通常」1つのままで足ります。**

口座を分けると便利なのは、たとえばこんなときです。

- 一部の貸し借りにだけ利子を付けたい（例：「通常」と「利子つき」に分ける）
- 立て替えと、まとまったお金の貸し借りを別々に見たい

利子の設定は口座ごとです。利子のしくみは[利子をつける](/help/interest)を見てください。

### 口座を追加する

相手のページの口座の見出しの右にある「追加」から、口座名（30文字まで）と年利を入れて作ります。年利を0%にすると、利子の付かない口座になります。

口座が2つ以上ある相手では、取引を記録するときに口座を選ぶ欄が出ます。

### 口座ごとに見る

口座が2つ以上ある相手のページでは、取引一覧の上に口座の名前が並びます。口座の名前を選ぶと、その口座の取引だけに絞り込めます。「すべて」で元に戻ります。絞り込んだまま「＋」ボタンを押すと、その口座が選ばれた状態で取引を記録できます。

### 口座の設定と削除

口座のカードの右にある設定アイコンから「口座の設定」を開き、口座名や利子の設定を変えられます。

口座の設定の下にある「この口座を削除」で口座を削除できますが、次の口座は削除できません。

- 取引が1件でも記録されている口座
- その相手の最後の1つの口座
