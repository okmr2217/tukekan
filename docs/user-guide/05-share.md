# 共有リンク

共有リンクを送ると、相手はログインせずに、あなたとの残高と取引の記録を見られます。「いくら貸してたっけ」を相手と同じ画面で確かめたいときに使います。**相手はツケカンのアカウントを作る必要がありません。**

## 共有リンクを発行する

1. 相手のページを開きます
2. 共有リンクのカードで「共有リンクを発行」を押します。発行したリンクはコピーされた状態になります
3. LINE やメールなどに貼り付けて、相手に送ります

あとからもう一度送るときは「リンクをコピー」を使います。「プレビュー」を押すと、相手に見えるページをそのまま確かめられます。

共有リンクは相手ごとに1つです。その相手とのすべての口座の記録が見られます。

## 相手に見えるもの

| 見えるもの | 見えないもの |
| --- | --- |
| あなたの表示名 | あなたのメールアドレス |
| その相手との残高の合計と、口座ごとの残高（利子のある口座は元本と未払利息） | ほかの相手の名前や記録 |
| 利子を付けている口座の、利子のルール | アーカイブした取引 |
| その相手とのすべての取引（金額・日時・**用途・メモ**） | 取引を作った日時・更新した日時 |
| 共有メモ（書いたときだけ） | |

**取引のメモも相手に見えます。** 相手に見せたくないことはメモに書かないでください。

相手が見ているのは、開いた時点の記録です。あなたが取引を記録・修正すると、次に相手が開いたときに反映されます。

### 相手から見た向きで表示されます

公開ページは相手が読むためのページなので、**相手の立場で**表示します。

- あなたが相手に貸しているとき、公開ページでは「◯◯さん（相手）は△△さん（あなた）に返します」と、赤で表示されます
- 取引の「貸した」「借りた」なども、相手から見た言い方になります

色の決まり（緑は受け取る側・赤は返す側）は、アプリの中と同じです。見る人が変わるので、同じ残高でも色が逆になります。

## 共有メモ

共有リンクがあるときは、カードに「共有メモ」の欄が出ます。ここに書いた内容が、公開ページに「△△さんからのメモ」として表示されます。

- 100文字まで。相手ごとに1つです
- 例：「月末までに半分返してくれると助かります」「振込先：◯◯銀行…」
- 空にすると、公開ページには出なくなります
- リンクを再発行しても、共有メモは残ります

## 有効期限・再発行・無効にする

- **有効期限は、発行してから90日です。** カードに「有効期限：◯月◯日まで」と出ます。期限が切れたリンクを開くと「このリンクは無効または期限切れです」と表示されます。続けて見せたいときは、もう一度発行してください
- **リンクを再発行する**：カードのメニューから選びます。新しいリンクを発行し、これまでのリンクは開けなくなります。相手には新しいリンクを送り直してください
- **リンクを無効にする**：カードのメニューから選びます。リンクを知っている人も、もう開けなくなります

## 気をつけること

**リンクを知っている人は、誰でもログインなしで開けます。** 相手がリンクを誰かに転送すると、その人も見られます。見せる必要がなくなったら、リンクを無効にしてください。

相手をアーカイブしても、共有リンクはそのまま使えます。
