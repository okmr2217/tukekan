# 利子をつける

口座に年利を設定すると、毎週決まった曜日に利息が自動で記録されます。利子を使わないなら、この記事は読まなくてかまいません（口座の年利は最初0%です）。

## 設定する場所

利子の設定は口座ごとです。

- 新しく口座を作るとき：相手のページの口座の見出しにある「追加」から、年利を入れて作ります
- 作った口座を変えるとき：口座のカードの設定アイコンから「口座の設定」を開きます

一部の貸し借りにだけ利子を付けたいときは、「利子つき」のような口座を別に作って分けるのがおすすめです（[相手と口座](/help/partners)）。

| 項目 | 内容 |
| --- | --- |
| 年利 | 0〜5,200%。0%にすると利子は付きません |
| 利息が発生する曜日 | 日曜〜土曜から選びます。口座を作ったときは水曜です |
| 利息のかかり方 | 「元本」（元本にだけ利息がつく）か「元本＋未払利息」（元本＋未払利息に利息がつく） |

## 利息の計算

**1週間ぶんの利息は、年利 ÷ 52 で計算します。** 1円未満は四捨五入します。

> 例：年利52%（週1%）、元本10,000円の口座 → 1週間で100円の利息
> 例：年利260%（週5%）、元本10,000円の口座 → 1週間で500円の利息

利息は、選んだ曜日の0時（日本時間）に週1回だけ付きます。その時点の残高で計算します。

### 利息が付くのは、相手に貸しているときだけ

利息が付くのは、口座の残高がプラス（相手に貸している状態）のときだけです。あなたが借りている口座や、精算済みの口座には付きません。

## 未払利息と元本

付いた利息は元本には足さず、**「未払利息」として別にたまっていきます。** 相手のページの残高や口座のカードには、合計といっしょに「元本」と「未払利息」の内訳が出ます。

```
合計残高 ＝ 元本 ＋ 未払利息
```

### 返済は、まず未払利息に充てられる

返済を記録すると、まず未払利息から減っていきます。未払利息が0になってから、残りで元本が減ります。

> 例：元本10,000円、未払利息500円のときに、3,000円返してもらった
> → 未払利息 500円 → 0円、元本 10,000円 → 7,500円

### 元本と、元本＋未払利息の違い

| 利息のかかり方 | 利息の計算のもとになる額 | 特徴 |
| --- | --- | --- |
| 元本 | 元本だけ | 返済がなくても、毎週の利息は同じ額のまま |
| 元本＋未払利息 | 元本と、まだ返してもらっていない利息の合計 | 返済がないと、利息にも利息が付いて毎週少しずつ増える |

## 次回の利子を確かめる

利子を設定した口座では、口座のカードと口座の設定に「次回の利子」として、次に利息が付く日と見込みの額が出ます。残高がプラスでないときは「次回は発生しません」と出ます。

## 知っておくこと

- **さかのぼっては付きません。** 年利を設定した日より前の週のぶんは計算しません。次に来る発生曜日から付き始めます
- **自動で付いた利息も、ふつうの取引と同じように直せます。** 一覧では琥珀色の「利息」として出ます。編集・アーカイブ・削除のしかたは[取引と残高](/help/transactions)を見てください
- **過去の取引を直すと、内訳も計算し直されます。** 元本と未払利息の内訳は取引から毎回計算しているので、過去の取引を編集・アーカイブすると、それに合わせて変わります。すでに付いた利息の額は変わりません
- **共有リンクの公開ページにも、利子のルールが表示されます。** 相手も「毎週◯曜日に、年利◯%の利息が発生する」ことを確かめられます

## 利息が付かないときは

次のどれかに当てはまっていないか確かめてください。

- 口座の年利が0%になっている
- 口座の残高がプラスではない（あなたが借りている、または精算済み）
- 相手をアーカイブしている（アーカイブ中の相手の口座には利息が付きません）
- まだ発生曜日の0時が来ていない
