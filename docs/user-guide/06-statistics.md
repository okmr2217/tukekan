# 統計の見かた

いまの残高はホームで見られます。統計では、**お金がこれまでどう動いてきたか**と、**返済にどれくらいかかっているか**を見ます。

統計は2つあります。

| 統計 | 開きかた | 見られるもの |
| --- | --- | --- |
| 全体の統計 | 下のタブの「統計」 | すべての相手をまとめた流れ・推移・返済の傾向と、相手ごとの比較 |
| 相手ごとの統計 | 相手のページの右上の統計アイコン | その相手との残高の推移・返済の傾向・よく使う用途・口座ごとの内訳 |

## 取引の分け方

統計では、取引を次の5つに分けて数えます。

| 分類 | 意味 |
| --- | --- |
| 貸した | 相手から借りていないときに、相手にお金を渡した |
| 返済された | 相手に貸しているときに、相手からお金を受け取った |
| 借りた | 相手に貸していないときに、相手からお金を受け取った |
| 返済した | 相手から借りているときに、相手にお金を渡した |
| 利息 | 利子を設定した口座に、自動で付いた利息 |

**残高が0をまたぐ取引は、2つに分けて数えます。**

> 例：3,000円貸している相手から5,000円受け取った
> → 「返済された 3,000円」と「借りた 2,000円」として数えます

## 全体の統計

画面の上で期間を「直近12ヶ月」「今年」「全期間」から選びます。

| 項目 | 内容 |
| --- | --- |
| 貸し借りの流れ | 期間中に動いたお金と取引の回数。「貸し」（貸したお金と、返してもらったお金）と「借り」（借りたお金と、返したお金）に分けて出します |
| 月ごとの推移 | 月ごとの棒グラフ。上が渡したお金（貸した・返済した）、下が受け取ったお金（借りた・返済された）。「月ごとの金額を表で見る」で数字の表も開けます |
| 残高の推移 | 月末の時点で、貸している金額・借りている金額がそれぞれいくらあったか |
| 返済の傾向 | 相手からの返済と、あなたの返済（下で説明します） |
| 動きのない貸し借り | 残高が残っているのに、60日以上取引がない相手 |
| 相手ごと | 期間中に動いた金額の多い順に相手が並びます。タップすると相手ごとの統計が開きます |
| 利息 | 期間中に付いた利息と、利子を設定した口座ごとの次回の見込み |

「返済の傾向」だけは、選んだ期間にかかわらず全期間で計算します。

## 相手ごとの統計

先頭に、その相手とのいまの残高・付き合いの長さ（最初の取引から）・取引の回数が並びます。

| 項目 | 内容 |
| --- | --- |
| 残高の推移 | 0より上は貸している、下は借りている |
| 返済の傾向 | 相手の返済と、あなたの返済。精算した回数も出ます |
| 貸し借りの流れ | これまでの合計 |
| 月ごとの推移 | 直近12ヶ月。上が渡したお金、下が受け取ったお金 |
| よく使う用途 | その相手との取引でよく使っている用途 |
| 口座ごと | 口座ごとの内訳。タップすると、その口座だけに絞り込めます |

## 返済の傾向の計算

「返済の傾向」は、貸したお金が返ってくるまで（借りたお金を返すまで）に、どれくらいかかっているかの目安です。

**貸し借りは、古いものから順に返済で埋まるとみなして計算します。**

> 例：1月1日に3,000円、1月10日に2,000円貸して、1月20日に4,000円返してもらった
> → 1月1日の3,000円は19日で全額返ってきた
> → 1月10日の2,000円のうち1,000円は10日で返ってきて、残りの1,000円はまだ返ってきていない

この考え方で、次の数字を出します。

- **平均日数**：返ってくるまで（返すまで）にかかった日数の平均。金額の大きい貸し借りほど重く数えます
- **1ヶ月以内に返ってきた割合**：30日以内に返済で埋まった金額の割合。まだ30日たっていない未返済のぶんは、どちらとも言えないので数えません
- **まだ返ってきていない額**：まだ返済で埋まっていない金額と、そのうち一番古いものがどれくらい前のものか

## 集計に含まれるもの

- アーカイブした**取引**は含みません
- アーカイブした**相手**との取引は含みます（相手ごとの一覧には「アーカイブ済み」と出ます）
