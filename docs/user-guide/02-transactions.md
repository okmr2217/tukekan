# 取引と残高

ツケカンでは、1回ぶんのお金のやり取りを「取引」と呼びます。この記事では、残高の読み方から、取引の記録・修正・検索までを順に説明します。

## 残高と色の見かた

### 金額の向きは2つだけ

取引には「貸した」「返済した」「借りた」「返済された」の4つの言い方がありますが、お金の向きで分けると2つしかありません。

| お金の向き | 言い方 | 残高への影響 |
| --- | --- | --- |
| 相手に渡した | 貸した・返済した | 相手から受け取るぶんが増える（返すぶんが減る） |
| 相手から受け取った | 借りた・返済された | 相手に返すぶんが増える（受け取るぶんが減る） |

「貸した」と「返済した」は、どちらも相手にお金を渡しています。違うのは、渡す前に貸していたか借りていたかだけです。ツケカンはそれまでの残高を見て、取引の一覧に出す言い方を自動で決めます。

> 例：相手に3,000円貸している状態で、相手から3,000円受け取ったと記録すると、その取引は「返済された」と表示され、残高は0円になります。

### 色は「受け取る側か、返す側か」

| 色 | 意味 |
| --- | --- |
| 緑 | あなたが受け取る側（相手に貸している） |
| 赤 | あなたが返す側（相手から借りている） |
| グレー | 貸し借りなし（精算済み） |

取引・残高・統計のどこでも、この色の決まりは同じです。[共有リンク](/help/share)で相手に見せるページでは、相手から見た向きで表示するので、色も逆になります。

### ホームの残高

ホームの先頭には、すべての相手をまとめた残高が出ます。

- **大きな数字**：貸しているぶんから借りているぶんを差し引いた額。「差し引きで受け取ります」「差し引きで返します」「差し引きで貸し借りなし」のどれかが添えられます
- **貸している**：残高が緑の相手の合計
- **借りている**：残高が赤の相手の合計

その下の「相手ごとの残高」には、相手ごとに「貸している」「借りている」「精算済み」と金額が並びます。利子を付けている相手では、「うち利息」として利息の額も出ます（[利子をつける](/help/interest)）。

## 取引ボタンの表示

取引を記録するときに押すボタンは2つです。ボタンに出す言い方は、使い方に合わせて3種類から選べます。**どれを選んでも、記録される内容は同じです。**

| 設定 | こんな人に | 左のボタン（相手に渡した） | 右のボタン（相手から受け取った） | 最初に選ばれている側 |
| --- | --- | --- | --- | --- |
| 貸し借り両方 | 貸すことも借りることもある | 貸した・返済した | 借りた・返済された | 左 |
| よく貸す | 貸して返してもらうことが多い | 貸した | 返済された | 左 |
| よく借りる | 借りて返すことが多い | 返済した | 借りた | 右 |

ボタンの並び（左が「渡した」、右が「受け取った」）は、どの設定でも変わりません。設定はメニューの「設定」→「取引ボタンの表示」で変えられます。

## 取引を記録する

画面右下の「＋」ボタンを押すと、「新しい取引」が開きます。相手のページで押すと、その相手が選ばれた状態で開きます。

| 項目 | 内容 |
| --- | --- |
| 相手 | 最近あなたが記録した相手から順に並びます |
| 口座 | その相手に口座が2つ以上あるときだけ出ます（[相手と口座](/help/partners)） |
| 金額 | 円で入力します（1回1,000万円まで。小数や外貨は使えません）。下の2つのボタンで向きを選びます |
| 用途 | 1行のひとこと（100文字まで）。例：麻雀、ランチ、返済。これまでに使った用途が、よく使う順に候補として出ます |
| メモ | 割り勘の内訳や返す約束など、くわしい内容（1000文字まで、改行できます） |
| 日時 | ふつうは「現在」のまま。過去の取引を記録するときは「日時を指定」を選びます（未来の日時は選べません） |

必ず入れるのは相手と金額だけです。用途とメモは空のままでもかまいません。

## 取引の詳細と、記録の直しかた

取引をタップすると「取引の詳細」が開き、その取引の前と後で残高がどう変わったかを確かめられます。下のボタンから、取引を直せます。

| 操作 | どうなるか | こんなときに |
| --- | --- | --- |
| 編集 | 金額・用途・メモ・日時などを書き換えます | 金額や日付を間違えた |
| アーカイブ | 取引は一覧にグレーで残りますが、残高・統計・共有リンクのページからは外れます。「解除」でいつでも元に戻せます | いったん無かったことにしたいが、記録は残しておきたい |
| 削除 | 取引が完全に消えます。**元に戻せません** | 重複して記録したなど、残す必要がない |

迷ったらアーカイブを選んでおくと、あとから戻せて安心です。

## 精算する

「精算」という専用のボタンはありません。**返してもらった（返した）ことを、ふつうの取引として記録します。** 残高がちょうど0円になると、ホームや相手のページに「精算済み」と表示されます。

> 例：相手に3,000円貸していて、全額返してもらったとき
> 「＋」→ 相手を選ぶ → 金額に3,000と入れて「返済された」側のボタン → 記録
> 残高が0円になり、「精算済み」になります。

多めに受け取った場合も、そのまま記録してかまいません。3,000円貸している相手から5,000円受け取ったら、残高は「借りている 2,000円」になります。

## 自動で付いた利息の取引

利子を設定した口座では、毎週決まった曜日に「利息」の取引が自動で記録されます。一覧では琥珀色の「利息」として、ふつうの貸し借りと区別して表示されます。利息の取引も、ほかの取引と同じように編集・アーカイブ・削除できます。しくみは[利子をつける](/help/interest)を見てください。

## すべての取引から探す

下のタブの「すべての取引」には、すべての相手との取引が並びます。右下の「＋」ボタンの上にある検索・絞り込みのボタンから、次の条件で探せます。条件をかけている間は、ボタンに条件の数が出ます。

- **用途・メモで検索**：入れた言葉を含む取引だけを出します
- **相手で絞り込む**：相手を選びます（何人でも選べます）
- **並び替え**：日時が新しい順・古い順、金額が高い順・低い順

アーカイブした相手との取引も、この一覧には出ます。
