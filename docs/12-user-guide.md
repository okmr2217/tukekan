## 12.0 背景・目的

いまのヘルプは `/help`（`src/app/(main)/help/page.tsx`）の1ページに、見出しと短い説明を
並べただけの構成になっている。次の点が伝わりにくい。

- **金額の向きは2択なのに、名目は4通りある**こと（貸した／返済した／借りた／返済された）と、
  それが緑・赤の色や残高の符号にどう結びつくか
- **口座**が何のためにあるのか、多くの人は1つのままでよいこと
- **利子**の仕組み（年利 ÷ 52 の週利・未払利息を元本と分ける・返済はまず利息から）
- **共有リンク**で相手に何が見えるか（相手から見た向きで符号と色が逆になる・期限90日・共有メモ）
- **相手のアーカイブ**で変わること・変わらないこと（利息だけは止まる）
- 統計の「返済の傾向」がどう計算されているか

これらを機能ごとの記事に分け、**各画面から該当する記事へ1タップで行ける**ようにする。
**いまのヘルプは廃止し、ガイドに置き換える**（中身は引き継がず、記事として書き直す）。

### 現行ヘルプの誤り（ガイドでは正しく書く）

| 現行ヘルプの記述 | 実装 |
| --- | --- |
| 「精算」：相手ページから精算すると残高をゼロにする取引が自動で作られる | 精算ボタンは無い。残高が0のとき「精算済み」と表示されるだけ。精算は返済の取引を記録して行う |
| 取引のアーカイブ：「フィルタで非表示にもできます」 | すべての取引の絞り込みにアーカイブの表示切り替えは無い |

## 12.1 決定事項

| 項目 | 決定 |
| --- | --- |
| 配信方式 | **アプリ内**（`/help`・`/help/[slug]`）。Clipnote のような外部配信はしない |
| ログイン前の閲覧 | **読める**。ログイン画面・新規登録画面からも行ける |
| 現行ヘルプ | **廃止**して新しく作る |
| 「パスワードを忘れた」「退会したい」 | 機能が無いので**ガイドでは案内しない** |
| パスワードの最低文字数 | **8文字**にそろえた（新規登録と設定のパスワード変更の両方） |
| 記事数 | **6本**（12.2） |

## 12.2 記事構成

| # | slug | タイトル | 内容 |
| --- | --- | --- | --- |
| 01 | `getting-started` | ツケカンをはじめる | ツケカンとは（自分ひとりで記録する・相手のアカウントは不要・相手に通知はいかない）／3ステップ（相手を追加 → 取引を記録 → 残高を見る）／登録と初期設定（表示名 → 取引ボタンの表示 → 最初の相手 → 最初の取引。後ろ2つは「あとで」可）／画面の見取り図（ボトムバー4タブ・右下の＋）／ホーム画面に追加／設定でできること（表示名・パスワード・取引ボタンの表示・外観・ログアウト） |
| 02 | `transactions` | 取引と残高 | **残高と色の見かた**（金額の向きは2択・緑 = 受け取る側・赤 = 返す側・「精算済み」・ホームの合計）／取引ボタンの表示3種類とそれぞれの言い方／**記録する**（＋ボタン・相手ページからだと相手と口座が選ばれた状態・相手の並び順・金額・用途のサジェスト・メモ・日時・口座）／**直す**（編集・アーカイブ・削除の違い）／**精算する**（返済の取引を記録する）／**探す**（すべての取引：用途・メモで検索・相手で絞り込み・並び替え） |
| 03 | `partners` | 相手と口座 | **相手**（追加・アプリ未登録の人でよい・名前の変更・削除）／相手ページの見かた（合計残高・口座カード・取引履歴）／**アーカイブ**で変わること・変わらないこと（一覧と候補から消えるだけ・残高や統計には残る・利息は止まる）とアーカイブ済みの相手の一覧／**口座**（貸し借りのまとまり・多くの人は1つのままでよい・分けるとよい例・追加・口座で絞り込む・削除できない条件） |
| 04 | `interest` | 利子をつける | 年利で指定・週の利息 = 年利 ÷ 52（例：年利260% → 週5%）／選んだ曜日の0時（日本時間）に週1回／対象は残高がプラスの口座だけ・アーカイブ中の相手は対象外／未払利息として元本と分けてたまる／返済はまず利息に充てられる／単利と複利／次回の発生日と見込み額／過去の取引を直すと内訳も計算し直される／利息が付かないときに確かめること |
| 05 | `share` | 共有リンク | 発行する（相手はログイン不要）／相手に見えるもの・見えないもの（相手から見た向きで表示＝符号と色が逆・メールアドレスは出ない）／共有メモ／プレビュー／有効期限90日・再発行と無効化／URLを知っている人は誰でも見られる |
| 06 | `statistics` | 統計の見かた | 全体の統計と相手ごとの統計／期間（直近12ヶ月・今年・全期間）／名目5分類と、残高が0をまたぐ取引の分け方／返済の傾向の計算（古いものから埋まるとみなす・平均日数・1ヶ月以内の割合・未返済額）／動きのない貸し借り／集計対象（アーカイブ済みの取引は含まない・アーカイブ済みの相手は含む） |

### 減らし方（前の案の11本から）

- **「残高と色の見かた」「取引の記録」「すべての取引」を 02 にまとめる**。どれも「取引」の話で、
  色の考え方を記録の手前に置けば1本で順に読める
- **「相手」と「口座」を 03 にまとめる**。口座は相手ページの中にしか出てこない
- **「設定」を 01 に入れる**。設定の項目（表示名・取引ボタンの表示）は登録直後の初期設定と同じもの
- **「よくある質問」をやめ、各記事の中に書く**。相手への通知・相手のアカウント要否は 01、
  精算・間違えた取引は 02、利息が付かないときは 04、共有をやめたいときは 05
- **利子（04）は口座から分けたまま**にする。使う人が限られ、口座の説明に混ぜると
  利子を使わない人が「口座は難しいもの」と受け取ってしまう

### 入力の上限は、その入力を説明する箇所に書く

| 項目 | 値 | 書く記事 |
| --- | --- | --- |
| 表示名 | 50文字 | 01 |
| パスワード | 8文字以上 | 01 |
| 取引の金額 | 1回 1,000万円まで（円・整数） | 02 |
| 用途 | 100文字 | 02 |
| メモ | 1000文字 | 02 |
| 相手の名前 | 50文字（同じ名前の相手は作れない） | 03 |
| 口座名 | 30文字 | 03 |
| 年利 | 0〜5,200% | 04 |
| 共有メモ | 100文字 | 05 |
| 共有リンクの有効期限 | 90日 | 05 |

## 12.3 原稿の書き方の決めごと

- 原稿は `docs/user-guide/{NN}-{slug}.md`（`NN` が並び順、`slug` が URL と画面からの参照に使う識別子）。
  front matter は `title` だけ
- 読者はエンジニアではない前提で、内部名（Partner・Ledger・Transaction・`amount`・`kind` など）は本文に出さない
- 画面上の表示名と一致させる：「相手」「口座」「取引」「すべての取引」「統計」「メニュー」「共有リンク」「共有メモ」「未払利息」「元本」「アーカイブ」
- 記事間のリンクは `/help/{slug}`（見出しへは `/help/{slug}#…`）と直接書く。アプリ内で配信するので、Clipnote のようなプレースホルダーは要らない
- 例は具体的な金額で書く（「3,000円貸している相手から5,000円受け取ったら」のように）
- 各記事の末尾に「もっと知る」として関連記事を2〜3本並べる
- ログイン前の人も読むので、「あなたの○○」のように自分のデータがある前提の書き方は避ける

## 12.4 画面

| パス | 内容 |
| --- | --- |
| `/help` | ガイドの目次。記事を番号順にカードで並べる |
| `/help/[slug]` | 記事本文。末尾に前後の記事へのリンク |

- **`src/app/(main)/` の外に置く**（`src/app/help/`）。`(main)/layout.tsx` は未ログインを弾き、
  オンボーディング未完了なら `/onboarding` へ送るため、その中にあるとログイン前やオンボーディング中に読めない
- ヘッダーの戻る先はログイン状態で変える（ログイン中 → `/menu`、未ログイン → `/login`）。
  ボトムバーと＋ボタンは出さない（未ログインでも同じ見た目にするため）
- 記事の本文はビルド時にバンドルへ取り込む（Workers では実行時にファイルを読めない）。
  Markdown の描画方法は実装時に `node_modules/next/dist/docs/` の MDX の案内を確認して決める
- 記事ごとに `title` をページタイトルにする。ログイン前に読めるので検索エンジンからも辿れる

## 12.5 画面からの導線

各画面の見出しまわりから該当記事へ1タップで行けるようにする。ガイドは同じアプリ内なので、別タブでは開かない。

| 画面 | リンク先 |
| --- | --- |
| メニューの「ヘルプ」・設定の「ヘルプ」 | `/help`（ラベルは「使い方ガイド」に変える） |
| ログイン・新規登録 | `/help` |
| ホーム | `/help/transactions`（残高と色の見かた） |
| すべての取引 | `/help/transactions`（探す） |
| 相手ページ・相手の設定 | `/help/partners` |
| 相手ページの共有カード | `/help/share` |
| 口座の設定 | `/help/interest` |
| 統計・相手ごとの統計 | `/help/statistics` |
| 設定 | `/help/getting-started`（設定でできること） |

置かない導線

- 取引フォームなどのダイアログの中：1つの操作を終わらせるための画面で、外へ出るリンクは入力を途中で止めさせる
- オンボーディングの各ステップ：入力を終わらせることを優先する
